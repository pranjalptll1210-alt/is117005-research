# Explore 10 AI career paths

For actual employer titles, requirements, and local locations, use the [NY/NJ job directory](/jobs).

These background profiles are educational summaries, not copied job advertisements. Titles and requirements vary by employer. **Evidence labels distinguish official occupations, adjacent forecasts, and emerging specialties.** Suggested entry routes and portfolio projects are this project’s recommendations.

## Data scientist

**Established occupation · official growth evidence**

Turn data into findings and predictive models that help teams make decisions.

- **Typical work:** Clean datasets, explore patterns, test predictive models, and communicate uncertainty.
- **Core skills:** Python, SQL, statistics, visualization, experimental design.
- **Possible entry route:** Build statistics and programming foundations; investigate analyst internships and junior data roles. BLS lists a bachelor’s degree as typical entry education.
- **Portfolio idea:** Analyze a public dataset, compare a baseline with a predictive model, and explain errors and limitations.

**Growth evidence:** 35% projected U.S. growth, 2025–2035, for the whole data-scientist occupation.

Background: [BLS data scientists](https://www.bls.gov/ooh/math/data-scientists.htm). The specialty descriptions synthesize these practices; the source does not necessarily use the same job title.

## Machine learning engineer

**Established specialization · global role-family outlook**

Build software that turns machine learning models into usable products.

- **Typical work:** Prepare training pipelines, compare models, serve predictions, and work with software teams on reliability.
- **Core skills:** Python, software engineering, model evaluation, APIs, testing.
- **Possible entry route:** Start with software development and applied ML projects; seek software or ML internships.
- **Portfolio idea:** Deploy a small classifier behind an API with tests, a baseline, and a clear model report.

**Growth evidence:** WEF identifies AI and ML specialists among fast-growing roles; no U.S. title-specific rate is assigned here.

Background: [WEF jobs outlook](https://www.weforum.org/publications/the-future-of-jobs-report-2025/2-jobs-outlook/). The specialty descriptions synthesize these practices; the source does not necessarily use the same job title.

## Generative AI / AI agent engineer

**Emerging specialty · no separate forecast established**

Build applications where language models retrieve information or use tools to complete bounded tasks.

- **Typical work:** Connect models to tools, design retrieval workflows, test failure cases, and set limits on autonomous actions.
- **Core skills:** TypeScript or Python, APIs, retrieval, evaluation, application security.
- **Possible entry route:** Develop web applications first, then add a model-powered feature with measurable quality targets.
- **Portfolio idea:** Build a cited course-notes assistant; evaluate unsupported answers and tool failures using a fixed test set.

**Growth evidence:** Technical practice supports this specialty, but does not establish its hiring growth rate.

Background: [Anthropic: Building effective agents](https://www.anthropic.com/research/building-effective-agents). The specialty descriptions synthesize these practices; the source does not necessarily use the same job title.

## MLOps / LLMOps engineer

**Operations specialty · no separate forecast established**

Keep model-based systems reproducible and dependable after deployment.

- **Typical work:** Automate delivery, version models and data, monitor quality, and support rollback.
- **Core skills:** CI/CD, containers, cloud fundamentals, observability, Python.
- **Possible entry route:** Build software or infrastructure experience, then learn the extra testing and monitoring needs of ML.
- **Portfolio idea:** Create a reproducible training pipeline with automated validation, deployment, and a rollback procedure.

**Growth evidence:** Production ML requires operations practices; this is not a quantified labor-market forecast.

Background: [Google Cloud: MLOps](https://docs.cloud.google.com/architecture/mlops-continuous-delivery-and-automation-pipelines-in-machine-learning). The specialty descriptions synthesize these practices; the source does not necessarily use the same job title.

## AI evaluation engineer

**Emerging specialty · no separate forecast established**

Measure whether an AI system performs acceptably on realistic tasks and edge cases.

- **Typical work:** Create test datasets and scoring rubrics, compare versions, review failures, and report tradeoffs.
- **Core skills:** Python, statistics, test design, domain knowledge, clear writing.
- **Possible entry route:** Combine quality-assurance or analytics skills with model evaluation projects.
- **Portfolio idea:** Design a 50-case benchmark for a document assistant and publish the rubric, results, and failure analysis.

**Growth evidence:** An inferred career direction from AI testing and risk-management needs; no independent growth estimate is claimed.

Background: [NIST AI Risk Management Framework](https://www.nist.gov/itl/ai-risk-management-framework). The specialty descriptions synthesize these practices; the source does not necessarily use the same job title.

## AI security engineer

**Security specialty · adjacent occupational evidence**

Protect AI applications, their data, and their integrations from misuse and attacks.

- **Typical work:** Threat-model an application, test access boundaries, examine unsafe inputs, and coordinate mitigations.
- **Core skills:** Application security, Python, identity and access, threat modeling, AI system behavior.
- **Possible entry route:** Learn security and software fundamentals; security analyst experience can support later AI specialization.
- **Portfolio idea:** Threat-model a local AI assistant and document tests for data exposure and unauthorized tool use.

**Growth evidence:** BLS projects 21% growth for information security analysts, not specifically AI security engineers.

Background: [BLS information security analysts](https://www.bls.gov/ooh/computer-and-information-technology/information-security-analysts.htm). The specialty descriptions synthesize these practices; the source does not necessarily use the same job title.

## AI governance / responsible AI analyst

**Emerging specialty · no separate forecast established**

Help teams identify, document, and manage risks throughout an AI system’s lifecycle.

- **Typical work:** Maintain system inventories, collect evaluation evidence, document limitations, and coordinate review.
- **Core skills:** Risk assessment, stakeholder interviews, documentation, data literacy.
- **Possible entry route:** Combine business, policy, or technical study with practical understanding of model behavior.
- **Portfolio idea:** Write a risk register and review checklist for a fictional campus AI assistant.

**Growth evidence:** NIST provides a risk-management framework; it does not forecast employment for this title.

Background: [NIST AI Risk Management Framework](https://www.nist.gov/itl/ai-risk-management-framework). The specialty descriptions synthesize these practices; the source does not necessarily use the same job title.

## AI product manager

**Product specialization · no separate forecast established**

Define which user problems an AI product should solve and how success will be measured.

- **Typical work:** Interview users, prioritize features, set quality targets, and coordinate delivery across teams.
- **Core skills:** Product discovery, metrics, communication, experimentation, AI literacy.
- **Possible entry route:** Develop product or domain experience; investigate associate product or business analyst routes.
- **Portfolio idea:** Write a product brief comparing an AI solution with a simple alternative, including acceptance criteria and costs.

**Growth evidence:** A career option inferred from cross-functional AI delivery; no measured title-specific growth is claimed.

Background: [NIST AI Risk Management Framework](https://www.nist.gov/itl/ai-risk-management-framework). The specialty descriptions synthesize these practices; the source does not necessarily use the same job title.

## Data engineer for AI

**Data infrastructure specialty · no separate forecast established**

Build dependable data pipelines that support model training and AI applications.

- **Typical work:** Validate incoming data, transform datasets, track lineage, and support repeatable workflows.
- **Core skills:** SQL, Python, data modeling, pipelines, testing.
- **Possible entry route:** Start with databases and programming; build a pipeline before adding distributed infrastructure.
- **Portfolio idea:** Create a public-data ingestion pipeline with schema checks, lineage notes, and documented refresh steps.

**Growth evidence:** This is an inferred specialization supporting ML pipelines, not a separate official growth estimate.

Background: [Google Cloud: MLOps](https://docs.cloud.google.com/architecture/mlops-continuous-delivery-and-automation-pipelines-in-machine-learning). The specialty descriptions synthesize these practices; the source does not necessarily use the same job title.

## AI research scientist

**Research specialization · adjacent occupational evidence**

Investigate methods that improve the capabilities or understanding of AI systems.

- **Typical work:** Read papers, design experiments, compare methods, and communicate reproducible findings.
- **Core skills:** Linear algebra, probability, optimization, programming, research writing.
- **Possible entry route:** Seek undergraduate research and advanced study; BLS lists a master’s degree as typical for the broader occupation.
- **Portfolio idea:** Reproduce a manageable published experiment and explain where your result differs.

**Growth evidence:** BLS projects 22% growth for computer and information research scientists; this broader category is not AI-only.

Background: [BLS computer and information research scientists](https://www.bls.gov/ooh/computer-and-information-technology/computer-and-information-research-scientists.htm). The specialty descriptions synthesize these practices; the source does not necessarily use the same job title.

## What about prompt engineering?

Prompt design is a useful skill within application development, evaluation, product work, and domain-specific workflows. This project does not establish that a standalone prompt-engineer title is a durable, fast-growing career. Pair prompting with software, analytics, evaluation, or subject-matter expertise.
