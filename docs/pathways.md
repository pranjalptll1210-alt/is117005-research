# Build a pathway into AI

This is a suggested student learning plan, not a promise of job readiness in a fixed number of weeks. Adapt it to your background and course workload.

## Start with a shared foundation

Learn Git, basic Python or JavaScript, data literacy, and clear technical writing. Practice reading documentation, checking outputs, and explaining limitations. For model-building paths, add probability, statistics, and linear algebra.

## Choose one direction

| Track | Build next | Possible stepping-stone roles |
| --- | --- | --- |
| Software → applied AI | APIs, testing, retrieval, model evaluation | Software intern, junior developer |
| Analytics → data science | SQL, statistics, predictive modeling | Data analyst intern, research assistant |
| Infrastructure → MLOps | Linux, containers, CI/CD, monitoring | Cloud support, software or operations intern |
| Security → AI security | Access control, threat modeling, application security | Security intern, security analyst |
| Business / policy → product or governance | User research, risk documentation, AI literacy | Business analyst, product intern, risk analyst |
| Mathematics → AI research | Experimental methods, paper reproduction | Undergraduate research assistant, graduate study |

These are suggested routes, not guaranteed progressions. Review current postings in your region for actual prerequisites.

## A 12-week portfolio plan

- **Weeks 1–3: Foundations.** Choose a track, learn its essential tools, and reproduce a small example. Keep notes in GitHub.
- **Weeks 4–6: First project.** Select a narrow problem and build a working baseline using public or synthetic data.
- **Weeks 7–9: Evidence.** Define success metrics, test failure cases, and compare your approach with the baseline.
- **Weeks 10–12: Communication.** Publish a clear README, architecture explanation, results, limitations, and a short demo. Seek feedback and revise.

## Make the portfolio credible

A good project explains the problem, data source, approach, evaluation method, results, and limitations. Include reproducible setup instructions. Discuss what failed and how you would improve it. Avoid presenting generated answers as verified facts or using private data without permission.

## Search by responsibilities as well as titles

Try combinations such as “machine learning internship,” “AI evaluation,” “model deployment,” “data pipeline,” or “responsible AI.” Compare responsibilities across postings and record recurring skills. A title alone is a weak signal of what the job actually involves.
