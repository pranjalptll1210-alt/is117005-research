# Compare your career options

Use the work you enjoy as a starting point. The coding levels below are this project’s qualitative guidance, not formal occupational requirements. Many specialist roles expect experience in a broader discipline first.

| If you enjoy… | Explore… | Coding emphasis | Portfolio evidence |
| --- | --- | --- | --- |
| Finding patterns and explaining results | Data scientist | High | Reproducible analysis and error discussion |
| Shipping useful software | ML engineer | High | Tested model API |
| Connecting models, tools, and interfaces | AI agent engineer | High | Bounded assistant with evaluation results |
| Keeping systems reliable | MLOps / LLMOps engineer | High | Automated pipeline and rollback plan |
| Finding failures and measuring quality | AI evaluation engineer | Medium–high | Benchmark, rubric, and failure report |
| Investigating attacks and protecting data | AI security engineer | High | Threat model and controlled security tests |
| Assessing risk and coordinating review | AI governance analyst | Low–medium | Risk register and review documentation |
| Understanding users and setting priorities | AI product manager | Variable | Product brief and success metrics |
| Organizing and moving data | Data engineer for AI | High | Validated pipeline with lineage |
| Reading papers and running experiments | AI research scientist | High | Reproduced experiment |

## Three questions to narrow your search

1. **What do I want to produce?** Software, analysis, research, decisions, or documentation?
2. **What foundation do I already have?** Programming, statistics, writing, business knowledge, or security?
3. **What proof can I build this semester?** Choose one small deliverable with clear success criteria.
