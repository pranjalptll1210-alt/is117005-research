# Which AI roles can a student realistically pursue?

**Start with eligibility, then compare the work.** This guide interprets the existing November 5, 2026 job snapshot. It is not a new availability check or a prediction of your chances. Follow each record to the employer’s requirements before applying.

The sample contains **five explicit internships and three explicit new-grad roles**. CoreWeave is a separate, partially verified infrastructure lead with an inferred entry-level classification. Neither the word “intern” nor an omitted experience threshold establishes that a role is suitable for a beginner.

## Turn responsibilities into portfolio evidence

The employer examples below are evidence of the work. **The projects are our educational suggestions**, not employer instructions or guaranteed hiring routes.

| Direction | Evidence from actual postings | Suggested project and proof |
| --- | --- | --- |
| FDE / applied agents | Pace and Coinbase emphasize workflows, integrations, and adoption | Build a small workflow using synthetic data; show the integration, failure handling, and a measured before/after result |
| Systems / infrastructure | Chalk emphasizes query execution; Decagon includes infrastructure | Build a searchable data service; report latency, tests, and behavior under load |
| Security | Ripple and MTA describe AI integration controls and assessment | Threat-model a sample agent; test tool permissions and document how controls address specific threats |
| Evaluations / reliability | LangChain builds tracing, monitoring, and evaluation tooling | Create a small evaluation set, trace failures, compare versions, and explain remaining uncertainty |
| Governance / adoption | Dentsu reviews vendors and approvals; Merck tests tools and explains their use | Produce a tool comparison, risk register, and user guide using public or synthetic examples |

The security, evaluation, and governance examples are experienced roles in this sample. A relevant project can demonstrate learning; it does not replace their stated professional experience. More directly verified junior opportunities in these areas remain a [research priority](/local-findings#questions-the-next-research-round-must-answer).

## Read experience and seniority separately

The directory now shows **employer title seniority** separately from our **research experience group**. Dentsu’s Analyst and Engineer roles request five-plus years but do not carry a Senior title. They are grouped as **Experienced**. Ripple’s Senior Staff, LangChain’s Senior, and the manager/director/lead roles are grouped as **Senior / leadership**.

Use the full requirements, not the group label alone. Three years, five years, a graduate degree, and people-management experience are different barriers. The [methodology](/job-methodology) explains how the groups were assigned.

## A practical reading order

1. Check degree/graduation eligibility, prior experience, location, and work arrangement.
2. Compare the responsibilities with evidence you can already show.
3. Separate required qualifications from preferred skills and unstated details.
4. Open the exact employer posting to confirm availability and resolve uncertainty.
5. Use the [learning pathway](/pathways) to plan development around one direction.

The current sample can help identify possible routes. It cannot establish acceptance rates, typical starting pay, or the fastest-growing local title.
